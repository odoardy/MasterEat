MasterEat - Client SWA

Client JavaScript semplice per testare le principali API RESTful del servizio MasterEat.

1. Configurazione

Default: ../api. Se il client è aperto da /MasterEat/swa-client/, le chiamate arrivano a /MasterEat/api.

2. Autenticazione

POST /auth/login Pubblico

POST /auth/logout Protetto

Utenti seed disponibili:

Username Password Ruolo
test_cliente password CLIENTE
test_staff password PERSONALE
test_owner password PROPRIETARIO

Token corrente

Nessun token salvato

3. Catalogo

Menu completo

GET /menu Pubblico

Ricerca prodotti

GET /prodotti?nome=&prezzoMin=&prezzoMax= Pubblico

I parametri vuoti non vengono inviati.

Dettaglio prodotto

GET /prodotti/{id} Pubblico

Caratteristiche prodotto

GET /prodotti/{idProdotto}/caratteristiche Pubblico

Ingredienti prodotto

GET /prodotti/{idProdotto}/ingredienti Protetto

Usare test_staff o test_owner.

4. Ordini cliente

Queste operazioni richiedono un token CLIENTE e alcune modificano dati reali.

Crea ordine in bozza

POST /ordini Protetto Modifica dati

Aggiungi prodotto all'ordine

POST /ordini/{idOrdine}/prodotti Protetto Modifica dati

Prodotti nell'ordine

GET /ordini/{idOrdine}/prodotti Protetto

Totale ordine

GET /ordini/{idOrdine}/totale Protetto

Tempo consegna

GET /ordini/{idOrdine}/tempo-consegna Protetto

Conferma ordine

POST /ordini/{idOrdine}/conferma Protetto Modifica dati

Annullamento ordine

DELETE /ordini/{idOrdine} Protetto Modifica dati

Annulla l'ordine impostando lo stato ANNULLATO. Il record resta nel database.

5. Staff / Proprietario

Usare test_staff o test_owner. Con un utente CLIENTE alcune risposte attese sono 403 Forbidden.

Ordini filtrati

GET /ordini?stato=&dataDa=&dataA= Protetto

Aggiorna stato ordine

PUT /ordini/{idOrdine}/stato Protetto Modifica dati

Operatori ordine

GET /ordini/{idOrdine}/operatori Protetto

6. Output

Nessuna richiesta eseguita
Usa uno dei pulsanti sopra per inviare una richiesta.
